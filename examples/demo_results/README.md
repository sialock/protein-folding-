# Checked demo results

These artifacts are generated by the `protein-mc` CLI using the **synthetic** 24-residue alpha-helical C-alpha model in `examples/synthetic_helix_ca.pdb`:

```bash
protein-mc run --pdb examples/synthetic_helix_ca.pdb --chain A \
  --steps 600 --scramble-steps 120 --seed 42 --report-every 10 \
  --outdir results/readme-demo
```

- `metrics.csv` is the complete recorded metrics trace from the example run.
- `best_ca.pdb` is a C-alpha-only lowest toy-energy sample, **not an experimentally validated structure**.
- The corresponding plots are in `assets/`; parameters and SHA-256 provenance are in `docs/example_summary.json`.

For reproducibility regenerate outputs rather than treating the provided toy outputs as scientific evidence.
